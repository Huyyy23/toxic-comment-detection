# TV4 validation ablations

`ablation.csv` contains 33 per-seed rows (seeds 42, 43, 44) for the requested CNN-02 contrasts and the separate CNN-01 vs CNN-01-WD weight-decay comparison. The three CNN-02 rows are shared, seed-matched controls referenced by the relevant comparison rows. Contrast definitions/levels come from `artifacts/TV4-cnn-analysis/tv4_phase4_report.json`; run IDs, metrics, validation hashes, thresholds, ECEs, and source paths come from `artifacts/N8/cnn/n8_cnn_report.json`.

`val_macro_f1` and `val_f1_toxic` are the official raw validation metrics at threshold 0.5. `threshold` is N8's separately selected threshold, fit by sweeping validation predictions to maximize validation Macro-F1; thus it is validation-fitted and in-sample, not held-out. `calibrated_ece` is post-Platt ECE computed on validation, also validation-fitted/in-sample; `raw_ece` is the uncalibrated validation ECE. Do not interpret optimized threshold results as held-out performance.

All rows use validation parquet SHA256 `4c33430a520818078aef6bcc34b3e2573873445dc7040c5729313e11bb60197a` and N8 validation-ID SHA256 `7f454a9926bf0a616c54426513b98874b944ea06921c927cd336c2203152f01d`. Standard N2-training runs (all rows except `CNN-AUG-N4`) use training SHA256 `097b32bea731bf1a4771a8485155d339a96027d2819fe8a38aa2c9d2e2f32a73`; `CNN-AUG-N4` uses N4-training SHA256 `f57fbf0a55de6b08c8cba1cd366c3895bfed495f2817069f892ba27b5786542e`. Selection was restricted to the TV4 validation report/results and N8 CNN validation-calibration report; no test data or test artifacts were used.
