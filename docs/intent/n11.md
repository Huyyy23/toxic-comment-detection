# Ý định N11

- **Kết quả:** Tích hợp inference phân loại bình luận nhị phân CLEAN/TOXIC trên local, dùng baseline `.joblib` trước.
- **Người dùng:** Người dùng thử nghiệm ứng dụng và nhóm dự án.
- **Lý do:** Hoàn thiện API và giao diện để chạy end-to-end trong khi N10 chưa hoàn tất.
- **Thành công:** Frontend React gọi được FastAPI; `/predict`, `/health`, `/model-info` và nạp model `.joblib` được kiểm thử trên local.
- **Ràng buộc:** Giữ API contract ổn định; backend dùng adapter có thể thay thế bằng DL, PhoBERT hoặc Ensemble mà frontend không đổi. Chưa deploy public và chưa chốt production model cho đến khi N10 cùng các thí nghiệm liên quan hoàn tất.
- **Ngoài phạm vi:** Public deployment, đổi frontend/API contract khi bổ sung adapter, và tuyên bố model production trước gate N10.
