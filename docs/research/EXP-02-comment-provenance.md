# EXP-02 raw comment provenance and redistribution

## Conclusion

**Recommendation: REMOVE raw comment text from the checked-in error-analysis artifact** (or, if a small example is essential to reproduce an analysis, replace it with a genuinely de-identified/minimized example and obtain explicit dataset-provider permission first). This is a risk-based recommendation, not a determination that republication is unlawful. The sources establish public availability of comment-bearing files, but do not establish a license grant for the dataset itself: the Hugging Face copy explicitly tells users to obtain permission from UIT. The paper says its collection process removed named entities for anonymity, yet personal names/handles in a downstream sample show that effective de-identification cannot be assumed. A model-error result can ordinarily be reported using counts, labels, indices, or abstracted examples; verbatim comments are not required absent a specific analytical need.

## What the first-party sources establish

- The [Hugging Face UIT-ViHSD dataset card](https://huggingface.co/datasets/ura-hcmut/UIT-ViHSD) calls itself a **copy instance** of the original UIT dataset and says: “Please visit https://nlp.uit.edu.vn/datasets to obtain a usage permission before using this dataset.” Its YAML metadata separately labels it `cc-by-nc-sa-4.0`. These statements conflict in practical effect: a metadata license badge is not reliable evidence that the original provider authorized reuse/redistribution, particularly given the express permission notice. Treat the license status for the underlying dataset as **unclear / permission required**, not as proven CC BY-NC-SA authorization.
- The [official CC BY-NC-SA 4.0 deed](https://creativecommons.org/licenses/by-nc-sa/4.0/) permits sharing subject to attribution, non-commercial use, and share-alike terms, and explicitly warns that publicity/privacy rights may require separate permission. Even if the HF metadata license applies to the files, it does not settle those individual privacy interests or the conflict with the card’s UIT-permission notice.
- The [Hugging Face repository tree](https://huggingface.co/api/datasets/ura-hcmut/UIT-ViHSD/tree/main) lists `ViHSD_train.csv`, `ViHSD_validation.csv`, and `ViHSD_test.csv`; thus files containing dataset records are publicly downloadable from that copy. The tree alone does not prove permission to redistribute their contents.
- **Exact sample provenance check:** All 48 unique `id`/text/label samples in PR #3 matched the local source records exactly in text and matched text+label records in the Hugging Face CSV files pinned to revision [`16c4f67`](https://huggingface.co/datasets/ura-hcmut/UIT-ViHSD/tree/16c4f67cf509d4f9f36ca5b63c5503c7c8830557). The G0 manifest assigns all 48 to `val`; their local source files are 45 records from `vihsd_test.jsonl` and 3 from `vihsd_train.jsonl`. The three local raw-file SHA-256 values match `data/processed/vihsd_g0_v1/dataset_info.json`. This confirms corpus provenance and current G0 split assignment, not redistribution rights.
- The PR base tree (`668873b`) already tracks `data/raw/vihsd_train.jsonl`, `data/raw/vihsd_test.jsonl`, `data/processed/vihsd_g0_v1/train_val.jsonl`, and `manifest.json`. Therefore the PR does not introduce the underlying comments to this repository for the first time; it duplicates a selected 48 with error labels, adds a convenient indexed extract, and increases redistribution surface if that artifact is reused separately.
- The linked [UIT dataset page](https://nlp.uit.edu.vn/datasets) did not resolve to a dataset/terms page during this review; it redirected to the general UIT homepage. Therefore no additional provider license terms or permission procedure could be verified from that URL. The HF card itself directs users there for permission.
- The authors’ [original paper (arXiv full text)](https://arxiv.org/html/2103.11528v4), “A Large-scale Dataset for Hate Speech Detection on Vietnamese Social Media Texts,” says the authors collected users’ comments from Facebook pages and YouTube videos, then removed named entities “to maintain the anonymity.” It describes over 30,000 comments, and the paper includes a small set of illustrative comment excerpts. It does not, in the reviewed text, state a license for the underlying dataset or grant readers a right to redistribute its full raw contents. The arXiv page’s CC BY-NC-ND 4.0 notice applies to the **paper**, not automatically to the dataset or the user-authored comments reproduced in it.

## Public content, personal data, and utility

The artifact contains exact source comments, not synthetic examples. Some include apparent personal names or account handles; other samples are generic text. The available files do not establish whether each name/handle identifies a real person, whether the person is public, or whether consent was given. Treat those particular records as potentially identifying, rather than claiming every comment is personal data. Public posting and public download do not establish permission to republish or remove privacy interests. The authors describe the source material as social-network comments and say named entities were removed for anonymity; the sampled mirror still contains apparent identifiers, so effective de-identification cannot be assumed.

Error analysis needs enough evidence to explain model behavior (e.g. aggregate error categories, labels, token phenomena, or carefully redacted/minimal examples). The raw verbatim text of 48 comments is not shown by the available primary sources to be necessary. The paper itself demonstrates that linguistic phenomena can be discussed with selected, sometimes anonymized examples; it does not justify copying this particular set into a separate artifact.

## Recommendation and limits

**REMOVE** verbatim comments from the artifact by default. Preserve analysis through non-identifying statistics or short, carefully reviewed transformations; do not assume simple name masking is sufficient if distinctive wording remains searchable. If verbatim quotations are essential, first obtain documented permission from UIT and review each item for names, handles, URLs, and indirect identifiability. Do not describe the entire dataset as CC BY-NC-SA based only on HF metadata, and do not imply the paper’s publication license covers the corpus.

This finding is limited to the first-party material linked above; the intended UIT permission page was unavailable at review time, and no explicit dataset redistribution terms were verifiable there. It is a conservative governance recommendation, not legal advice.
